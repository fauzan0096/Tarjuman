This is your config.json. Copy it and replace the file in your GitHub repository. Changes reach everyone within a few minutes.

  1. Open your repository on github.com.
  2. Tap config.json, then the pencil icon (Edit).
  3. Select all, paste what you copied, tap Commit changes.

To remove one person: tap Remove next to their name, copy config.json again and commit it. To close everything: untick "App is ON", copy and commit.
